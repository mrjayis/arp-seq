# Fonts

- **geneva-9.ttf**: "Geneva 9", a recreation of the classic Mac bitmap font by
  Kelsey Higham (2010), made with FontStruct. Licensed under
  [Creative Commons Attribution 3.0](http://creativecommons.org/licenses/by/3.0/).
  Used for small text in the System 7 theme.

The System 7 theme asks for a locally installed font named "Chicago" (or the
common free recreations of it) first. None is bundled, because the original is
Apple's and no free recreation with a clear license could be verified. Without
one, titles fall back to Pixelify Sans (SIL Open Font License, served by Google
Fonts).
